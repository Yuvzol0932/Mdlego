## 3. 与参考图的差异清单（逐页，诚实）

> 参考图：`docs/design/reference.webp`（左机 夜间·暖黑 书架，右机 日间·米纸 阅读页）。
> 截图：`docs/screenshots/C/`（`c-shelf-*` / `c-reader-*` / `c-search-*` / `c-stats-*` / `c-settings-*`，`-warm-night` / `-warm-paper`）。

### 3.1 对比后「对上了」的部分
- 夜间底/卡片/琥珀金、日间米纸/锈红棕是**从参考图取样的**（见 DECISION §1），不是目测。
- 书架：顶栏左侧书形 logo + 应用名、右侧搜索/更多；圆角 24 的横幅（浅色字 + 深色块）、圆点分页；「继续阅读」标题 + 查看全部 + 横向卡（小封面/标题/进度/圆形播放键）；「我的书架」三列封面 + 标题 + 相对时间 + 细进度条；底部五项玻璃悬浮导航 + 中间凸起「＋」。
- 阅读页：返回/标题/搜索/书签/更多顶栏；H1 大号衬线 + 短强调色横线；正文衬线、行距 1.88；图片圆角；引用块浅底 + 强调色竖线 + 大号引号；H2 左侧强调色竖线；任务清单细勾线；底部 `已读 %` + 细进度条 + `Aa` + 明暗 + 下一章。
- 设计语言一致：同一套令牌、同一套圆角/间距/阴影、同一玻璃配方。

### 3.2 有意的差异（做了取舍，不是没做）
1. **封面与横幅不用摄影图**。任务书 §3.4 明确禁止硬塞摄影图：封面用「标题哈希取色（8 套令牌渐变）+ 首字大号衬线」，横幅用「主题色辉光 + 噪点」。参考图的雪山/森林是实景照片，这一层观感差异是**规格要求**。用户可在设置里选本地图片做横幅背景（叠暗角），这时能接近参考图。
2. **应用名用中文「墨读」**，参考图是英文「Mdlego」。品牌与既有测试（`app-title === 墨读`）一致；顶栏宽度与参考图相当。
3. **阅读页标题左对齐于可用空间**，不是页面绝对居中。参考图也是「返回 → 标题 → 图标组」左对齐；393px 宽放 5 个控件时绝对居中会与右侧图标重叠。已在 DECISION §3 记录。
4. **书架图标用现有「三本书」**，参考图是「书箱/房子」造型。没有为单个图标新增 SVG 分支（图标精灵要统一 24 栅格/2px 描边，重画收益低）。
5. **底部导航选中态**是图标上浮 + 缩放 1.12 + 强调色，没有参考图那种「指示点滑动」——滑动指示点属阶段 D 动效清单，这里只做静态选中态与按压反馈。

### 3.3 还没做到 / 明确未验证（下一阶段或需用户决定）
1. **翻页方式（仿真翻页）未实现**：当前是文档级滚动，翻页需要另一套渲染/分页管线，不在 C 范围。设置页因此没有放「翻页方式」这一项（不放假的入口）。
2. **选词工具栏（参考图右机底部深色胶囊：高亮/下划线/批注/查词/更多）未实现**：它依赖「划词批注」（阶段 E2）与「查词卡片」改造（E4）。当前长按查词沿用 M5 的查询卡片。
3. **备份与恢复、生词本**未实现（E3/E4）。设置「数据」区只放了真实的导入与清空统计，没有放占位按钮。
4. **统计页「最近读过」而非参考图没有的「最近读完」**：现有数据只有 bid + 滚动百分比，无法判定「读完」，不伪造。
5. **H1 章节眉标**只在标题以「第N章/数字编号」开头时出现（有 8 条单测）；本轮 fixture 的 H1 是「Markdown 进阶指南」，所以 C 截图里看不到眉标——代码路径已被测试覆盖。
6. **字体是系统字体栈**（标题宋体 / 界面无衬线），不打包字体文件；不同设备字形与参考图有差异。
7. **玻璃观感**：参考图底栏更「乳白」且带明显折射高光；我们的玻璃透明度由主题令牌与强度档决定，两套主题下已对比，但未逐像素对齐参考图。
8. **动效只做了必要过渡**：顶栏随滚动收放、Aa 面板滑入、柱状图生长、按压反馈。页面转场（View Transitions）、主题圆形扩散、卡片错峰进入属阶段 D。
9. **未在真机/模拟器验证**：系统返回键、低端机玻璃掉帧、刘海/手势条安全区。浏览器环境用 `--safe-top/--safe-bottom` 占位为 0，真机数值由原生层注入。
10. **统计会话的边界**：只在关闭阅读页 / 切 tab / 切后台 / pagehide 时落库；进程被强杀会丢「当前这段」会话（最多一段）。少于 3 秒的打开不计入，避免误点污染。

## 4. 已知技术债
- `--ease-spring` 用 `linear()` 近似，不支持的环境回落 standard（B 阶段遗留）。
- 「动效：简约」仍只有令牌、没有区分逻辑（阶段 D 的 `motion.ts`）。
- 全库搜索一次最多带 120 条命中（视图画 60），大库搜索会按「最近阅读」顺序截断，不做分页（E1 再扩）。
- 自定义横幅图压到 ≤900KB data URL 存 localStorage；超出会提示并用默认渐变（有代码与文案，未真机验证配额边缘）。
- `web/public/dict`（11MB 词库分片）仍在仓库里（交接文档已列为待用户决定）。
