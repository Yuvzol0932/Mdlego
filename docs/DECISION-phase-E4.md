# 阶段 E4 设计说明 · 查词完善

> 任务书 §6 E4：选词查词卡片（玻璃底面板）、生词本、查词历史、词库加载失败的降级提示。
> 现状：M5 已有离线词库、分片加载、词形还原、释义卡片；E2 把查词入口挪进选区工具条。E4 补齐卡片质感、生词本、历史与失败降级。

## 1. 查词卡片：玻璃底面板

- 卡片沿用 `.drawer--bottom` 的交互（遮罩点击关闭、返回键走 `lookup` 浮层），外观换成 `glass` + `.lookup-panel`：圆角上沿、玻璃底、顶部把手。
- 头部：单词、音标、**生词本按钮**、关闭；正文：音标行、分隔线、释义、词形提示（推断来的释义会标注「按 xxx 释义」）。
- 生词按钮三态可见：未收藏（书签图标 +「生词本」）、已收藏（对勾 +「已收藏」），点击立即持久化并提示。

## 2. 生词本与查词历史

### 2.1 存哪里、为什么

- 存在 IndexedDB `meta` 的两个键：`wordbook`（生词数组）、`lookupHistory`（历史数组）。
- **不建新仓库**：生词本几百级、整表读写足够；建仓库要升 DB 版本 + 写迁移与迁移测试，对预览版是过度设计。
- 读取与写回都走 `core/vocabulary.ts` 的归一化：脏数据被过滤而不是让界面崩。

### 2.2 规则

| 项 | 规则 |
| :--- | :--- |
| 单词归一化 | 去空白、转小写、`^[a-z][a-z'-]*$`、长度 2–64；非法丢弃 |
| 生词本去重 | 按 word；重复收藏视为更新（时间刷新），不重复占位 |
| 生词本上限 | 500 条；按收藏时间倒序 |
| 历史去重 | 按 word，同一个词只留最近一次；最新在前；上限 100 |
| 空释义 | 不收录（避免展示空词条） |

### 2.3 入口与面板

- 设置 →「查词」分区新增两行：**生词本 N 个**、**查词历史 N 条**，点击打开对应分段的浮层。
- 浮层（`LayerKind 'wordbook'`，玻璃底部面板 + 下拉关闭）分两段：
  - 生词本：单词 / 音标 / 释义（3 行截断）/ 删除；顶部「清空」；空态文案。
  - 查词历史：单词 + 时间（月-日 时:分）；顶部「清空」；空态文案。
- 点击历史条目不重新查词（历史面板拿不到正文上下文；避免做成「点了没反应」的伪交互）。

## 3. 词库加载失败降级

- 旧行为：`lookup()` 抛错被 catch 成 `{hit:false}` → 显示「未收录」，**把加载失败伪装成词库没有这个词**。
- 新行为：失败单独走 `mountDictError`：红色提示「词库加载失败，点此重试「word」」，点击重试；超过 4 秒自动消失。与「未收录」明确区分。
- 触发条件：分片 fetch 失败 / 解压失败 / 解析失败（data/dict.ts 抛错）。

## 4. 备份联动：schemaVersion 2

- `BackupData` 增加 `vocabulary`（生词本数组），`BACKUP_SCHEMA_VERSION` 升到 **2**。
- **v1 备份仍可恢复**：缺少 `vocabulary` 视为空生词本；校验和按原始 `data` 计算，不破坏旧文件。
- 查词历史**不写入备份**（任务书只要求生词本；历史是临时线索，不占备份体积）。
- 恢复时生词本随其他数据一起覆盖并同步回 state。

## 5. 明确不做（本项内）

- 单词发音（没有音频资源；不伪造播放按钮）。
- 复习/错词本/记忆曲线（E6 之后再看）。
- 生词本导出为 Markdown/Anki（备份已有 JSON，够用）。
- 历史条目点击回到原文位置（历史只存 word，不存锚点；避免「跳过去但找不到」）。
- 词库更新/下载（离线内置，不联网）。

## 6. 验收方式

- 单测：`core/vocabulary.test.ts`（归一化/去重/上限/排序/不修改输入）、`views/wordbook.test.ts`（分段/删除/清空/空态）、`core/backup.test.ts` 更新（v2、v1 兼容、生词本损坏拒绝）。
- smoke：选中 `inspect` → 工具条查词 → 玻璃卡片（单词+释义） → 收藏生词 → 设置显示生词本 1 / 历史 1 → 生词本面板含 inspect → 历史含 inspect；备份导出含 `"schemaVersion": 2` 与 `"vocabulary"`。
- 截图：`npm run shot:e4`（查词卡片、生词本、历史，日/夜两套）。
