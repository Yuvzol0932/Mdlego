# 阶段 E 设计说明 · 功能补全（E1 先行）

> 任务书 §6 阶段 E 要求「逐项独立可发布，按价值排序」。本文先定 E1 的边界与取舍，后续 E2–E6 各自补一节。
> 原则：不伪造内容、数据变更可回退、失败有明确降级、每项都有单测 + 一张 smoke 截图。

## E1 · 全库搜索 + 书架筛选/标签/收藏/文件夹

### 完成定义（DoD）

1. 全库搜索：结果按文档分组、显示命中数、关键词高亮、可切换「全部 / 仅收藏」；空结果/空书架有明确文案。
2. 书架：可切换筛选（全部 / 收藏 / 标签 / 文件夹），筛选后仍可排序、网格/列表、长按多选；筛选无结果显示空状态而不是空白。
3. 标签：多标签、可新增/移除；长按多选后可批量加标签；同名标签去空白与重复。
4. 文件夹：**单层**文件夹（不做嵌套）；长按多选后可移动/移出；书架可按文件夹筛选。
5. 数据：`Doc.tags` / `Doc.folder` 为可选字段，旧数据读出时补默认值；**不新增 IndexedDB 仓库/索引**，因此不升 DB 版本，但要有归一化测试与「旧文档可读」测试。
6. 失败降级：写库失败只提示、不假装成功；标签/文件夹非法输入被收敛而不是写坏数据。

### 数据模型

```ts
interface Doc {
  // 已有字段…
  /** 用户标签；旧数据没有该字段，读取时归一化为 [] */
  tags?: readonly string[];
  /** 单层文件夹名；null / 缺省表示未归档 */
  folder?: string | null;
}
```

- 为什么不上 IndexedDB 索引：标签/文件夹是**书架视图的本地筛选**，文档量级在千级以内，全量遍历足够；不建索引就不需要 schema 迁移，避免为可选字段升版本。
- 归一化：`core/library.ts` 的纯函数负责（去空白、去重、截断长度、限制每篇标签数），data 层读出后套用；写回时是合法的最终值。

### 交互与文案

| 位置 | 交互 | 空/失败态 |
| :--- | :--- | :--- |
| 书架筛选条 | 横向 chip：全部 / 收藏 / 各标签 / 各文件夹；单选；点已选中的再点回「全部」 | 筛选后 0 篇：`这个筛选下还没有文档` + 清除筛选按钮 |
| 长按多选 | 在原有「全选 / 删除 / 取消」上加「标签」「文件夹」 | 无选中时按钮禁用 |
| 标签面板 | 已有标签 chip（全选/部分/未选三态），点击加/移除；底部输入框新建 | 输入非法（空白/过长）不提交，按钮禁用 |
| 文件夹面板 | 已有文件夹 chip 单选；输入框新建；「移出文件夹」 | 同上 |
| 搜索页 | 分组结果（文档标题 + N 处 + 最多 3 条片段），片段内关键词 `<mark>`；范围 chip：全部文档 / 仅收藏 | 无结果：`没有找到「q」`；空库：引导导入 |

### 明确不做（本项内）

- **嵌套文件夹 / 拖拽归档**：单层足够表达「课程 / 项目」两类归档，嵌套会带来路径迁移与面包屑，收益低。
- **标签重命名/删除的全局管理页**：面板里支持对选中文档移除，标签本身会随文档消失；全局管理留给后续备份/整理功能。
- **搜索索引**：仍是按需渲染 + 内存匹配（E1 不引入索引结构，避免与编辑原文 E5 的一致性风险）；结果上限与提示沿用现有策略。

### 验收方式

- 单测：`core/library.test.ts`（归一化 / 筛选 / 三态 / 批量变更）、`views/search.test.ts`（分组 / 高亮 / 仅收藏）、`views/shelf.test.ts`（筛选条渲染与切换）。
- smoke：新增「筛选收藏 → 空态 → 清除」「多选加标签 → 标签 chip 出现在筛选条 → 按标签筛选」两组流程。
- 截图：`npm run shot:e` 生成 `docs/screenshots/E/`（筛选条、标签面板、搜索分组）。

## E2–E6（待开工时补）

- E2 划词批注：四色高亮/下划线/删除线/批注，锚点 `data-bid` + 偏移，失效标注可重挂；批注列表与 Markdown 导出。
- E3 备份恢复：JSON（文档/批注/进度/任务/设置/生词本）+ 版本与校验；WebDAV 可选。
- E4 查词完善：玻璃底查词卡片、生词本、查词历史、词库失败降级。
- E5 编辑原文：轻量编辑器 + 预览 + 回写原文件 + 冲突检测。
- E6 阅读增强：TTS、护眼、常亮（已有）、导出 HTML/PDF。
